# 影院模块接口文档

本文档对应当前后端已实现的影院、影厅和座位图创建接口，供前端联调使用。

## 约定

- 基础路径：`/api/v1`
- 请求与响应编码：`application/json; charset=UTF-8`
- 需要登录的接口携带：`Authorization: Bearer <accessToken>`
- 统一响应：`{ "code": 200, "message": "success", "data": {} }`
- 分页响应 `data`：`{ "items": [], "page": 1, "size": 20, "total": 0 }`
- 常见状态：`200` 成功、`400` 参数或业务校验失败、`401` 未登录、`403` 无权限、`404` 资源不存在、`409` 资源冲突。

角色说明：`admin` 可管理所有影院；`staff` 只能管理 JWT 中 `cinemaId` 对应的影院。

## 公开影院接口

### 查询影院列表

`GET /cinemas`

无需登录。`sort=distance` 时必须同时传 `lat`、`lng`；`sort=price` 可不传坐标。

| 参数 | 必填 | 说明 |
| --- | --- | --- |
| `movieId` | 否 | 电影 ID；传入后仅返回有该电影在售场次的影院 |
| `lat` | 距离排序时是 | 纬度，范围 `-90`~`90` |
| `lng` | 距离排序时是 | 经度，范围 `-180`~`180` |
| `radiusMeters` | 否 | 搜索半径，默认 `5000`，范围 `1`~`50000`；无坐标时不生效 |
| `sort` | 否 | `distance`（默认）或 `price` |
| `page` | 否 | 页码，默认 `1` |
| `size` | 否 | 每页数量，默认 `20`，最大 `50` |

示例：

```http
GET /api/v1/cinemas?lat=31.2304&lng=121.4737&radiusMeters=5000&sort=distance&page=1&size=20
```

`data.items` 中每项字段：

| 字段 | 说明 |
| --- | --- |
| `cinemaId` / `cityId` / `cityName` | 影院 ID、城市 ID、城市名称 |
| `name` / `address` | 影院名称、地址 |
| `distanceMeters` | 距离（米）；未传坐标的价格排序时为 `null` |
| `minPrice` | 满足筛选条件的在售场次最低价；无场次时为 `null` |

### 查询影院详情

`GET /cinemas/{cinemaId}`

无需登录。除影院基本字段外，响应还包含：

- `trafficNote`：交通说明
- `tags`：特色标签数组
- `halls`：影厅数组，每项为 `hallId`、`cinemaId`、`name`、`seatMapId`、`showCount`

## 影院管理

### 创建影院

`POST /admin/cinemas`，仅 `admin`。

```json
{
  "cinemaId": "c_sh_xuhui_001",
  "cityId": "city_sh",
  "cityName": "上海市",
  "name": "徐汇影院",
  "address": "上海市徐汇区示例路 1 号",
  "lat": 31.2001,
  "lng": 121.4302,
  "trafficNote": "地铁 1 号线直达",
  "tags": ["IMAX", "杜比"]
}
```

`cityName`、`name`、`address`、`lat`、`lng` 必填。`cinemaId` 可省略，服务端自动生成；`cityId` 可省略，默认 `city_sh`。成功后返回包含城市名称的影院详情。

### 更新影院

`PUT /admin/cinemas/{cinemaId}`，`admin` 或该影院的 `staff`。

请求体为局部更新，可传：`cityId`、`cityName`、`name`、`address`、`lat`、`lng`、`trafficNote`、`tags`。成功后返回影院详情。

### 删除影院

`DELETE /admin/cinemas/{cinemaId}`，仅 `admin`。无需请求体，成功响应为：

```json
{ "code": 200, "message": "success", "data": null }
```

该操作为软删除：影院记录的 `is_delete` 会标记为 `true`，不会删除影厅、座位图、场次和订单等历史关联数据。若仍有员工绑定该影院，接口会返回 `400`，需先在员工管理中将其迁移至其他影院。删除后，公开影院列表和详情接口均不可见；已删除影院不能再更新影院信息、查询或更新其影厅，也不能新增座位图或影厅。已删除的影院 ID 不可重复创建。

## 座位图管理

当前仅实现“创建座位图”接口；查询、更新和删除接口尚未提供。

### 创建座位图

`POST /seat-maps`，`admin` 或 `staff`。

```json
{
  "seatMapId": "sm_sh_xuhui_01",
  "cinemaId": "c_sh_xuhui_001",
  "rows": 8,
  "cols": 12,
  "screenLabel": "银幕",
  "seats": [
    { "graphRow": 1, "graphCol": 2 },
    { "graphRow": 1, "graphCol": 3, "type": "couple", "couplePairId": "pair_1" },
    { "graphRow": 1, "graphCol": 4, "type": "couple", "couplePairId": "pair_1" }
  ]
}
```

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `seatMapId` | 否 | 最大 32 位；省略时自动生成 |
| `cinemaId` | admin 是，staff 否 | staff 省略时自动使用其所属影院；显式传入其他影院会被拒绝 |
| `rows` / `cols` | 是 | 画布行列数，均大于 `0` |
| `screenLabel` | 否 | 默认“银幕” |
| `seats` | 是 | 非空座位数组 |
| `seats[].graphRow` / `graphCol` | 是 | 画布坐标，范围不能超过 `rows`、`cols`，且不能重复 |
| `rowNo` / `colNo` | 否 | 业务座位号；省略后服务端按画布位置自动生成 |
| `seatId` / `seatName` | 否 | `seatId` 可自定义；座位名称由服务端生成 |
| `type` | 否 | `normal`（默认）、`couple`、`disabled` |
| `zone` | 否 | 默认 `normal` |
| `defaultStatus` | 否 | `available`（默认）或 `unavailable` |
| `couplePairId` | 情侣座时是 | 同一 ID 必须恰好对应两张 `couple` 座位 |

成功响应的 `data` 包含 `seatMapId`、`cinemaId`、`rows`、`cols`、`screenLabel`、`mutable`、`seatCount` 和 `seats`。每个返回座位包含 `seatId`、`seatName`、业务坐标、画布坐标、类型、分区、默认状态和情侣座配对 ID。

## 影厅管理

### 创建影厅

`POST /halls`，`admin` 或 `staff`。

```json
{
  "hallId": "h_sh_xuhui_01",
  "cinemaId": "c_sh_xuhui_001",
  "name": "1 号厅",
  "seatMapId": "sm_sh_xuhui_01"
}
```

`name`、`seatMapId` 必填。`hallId` 可省略自动生成。`staff` 可省略 `cinemaId`，服务端自动取所属影院；座位图必须属于同一影院。成功后返回影厅对象。

### 查询运营端影厅列表

`GET /admin/halls`，`admin` 或 `staff`。

| 参数 | 必填 | 说明 |
| --- | --- | --- |
| `cinemaId` | admin 是，staff 否 | staff 只能查询所属影院 |
| `page` / `size` | 否 | 默认 `1` / `20`，`size` 最大 `50` |

返回分页影厅数组。

### 修改影厅名称

`PUT /admin/halls/{hallId}`，`admin` 或该影院的 `staff`。

```json
{ "name": "杜比全景声厅" }
```

`name` 必填，最大 128 个字符。成功后返回更新后的影厅对象。
